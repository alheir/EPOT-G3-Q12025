# TP1: Boost Converter

## Description
This assignment involves the design and simulation of a **Boost** (step-up) DC-DC converter topology.

## Project Structure
- `sim/`: Simulation files (LTspice or others).
- `Informe/`: Detailed design report and calculation memory (in Spanish).
- `assignment/`: Original assignment requirements.
- `entrega/`: Final delivery files.
- `imagenes/`: Screenshots and graphics used in the report.
